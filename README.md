# \# 📊 Data Professionals Survey Dashboard | Power BI

# 

# \## 📌 Project Overview

# 

# This project presents an interactive dashboard created using Microsoft Power BI to analyze survey data collected from 630 respondents in the data professional community.

# 

# The dashboard explores salary trends, programming language preferences, job satisfaction, work-life balance, and respondent demographics.

# 

# \## 🎯 Project Objectives

# 

# \- Explore the demographic distribution of survey respondents.

# \- Compare average salaries across different data-related job titles.

# \- Identify popular programming languages among respondents.

# \- Analyze job satisfaction and work-life balance.

# \- Explore respondents' happiness with their salaries.

# \- Present survey findings through interactive visualizations.

# 

# \## 🛠️ Tools and Technologies

# 

# \- Microsoft Power BI

# \- Data visualization

# \- Survey data analysis

# \- Interactive dashboard design

# 

# \## 📈 Dashboard Highlights

# 

# \- Country distribution of survey takers

# \- Average salary by job title

# \- Favourite programming languages

# \- Average age of respondents

# \- Gender distribution

# \- Work-life balance satisfaction

# \- Salary satisfaction
